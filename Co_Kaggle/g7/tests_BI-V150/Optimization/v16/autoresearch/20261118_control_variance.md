On the first repetition, the server reported a slow draining tail: from 23:49:43 to 23:51:33 host time, running requests fell from 59 to 0 with reported generation rates mostly 11–46 tokens/s. On the second, the server went from 64 running at 23:59:54 to 0 at 00:00:04, with 555.1 generated tokens/s in that sample. This is a temporal association, not a demonstrated cause; server metric sample boundaries and buffered client output limit precision. Both repetitions had zero recorded preemptions; 4,080 prefix-cache-hit tokens occurred across the pair. Warm-up/cache, request lifetimes, runtime and stochastic output differences remain possible sources. Do not use either raw repeat alone to claim a speedup.
