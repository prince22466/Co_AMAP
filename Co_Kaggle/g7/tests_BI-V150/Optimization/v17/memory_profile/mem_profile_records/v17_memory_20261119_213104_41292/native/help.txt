COMMAND ["/usr/local/corex/bin/ixkn-cli", "--help"]
IXplorer Kernel Analyzer CLI, ixkn-cli
Usage: /usr/local/corex/bin/ixkn-cli [OPTIONS] [cuda-app] [app-args]

Positionals:
  cuda-app TEXT               cuda-app
  app-args TEXT               cuda-app-arguments

Options:
  -h,--help                   Print this help message and exit
  --list-sets                 List all section sets.
  --set TEXT                  Identifier of section set to collect.
                              If not specified, the default set is collected.
                              Use "--list-sets" to get a list of available sets.
  --list-sections             List all sections.
  --section TEXT              Identifier of section to collect.
                              Multiple identifier separated by comma can be specified.
                              Use "--section all" to collect all sections.
                              Use "--list-sections" to get a list of available sections.
  --list-metrics              List all metrics to be collected based on selected sections.
  --query-metrics             List all the metrics available on the device.
                              Use --devices to filter which devices to query.
                              
  -m,--metrics TEXT           Specify the metrics to be profiled.
                              Multiple metric names separated by comma can be specified.
                              Use "--metrics all" to profile all metrics available.
                              Use "--query-metrics" to get a list of available metrics.
                              
  --profile-child-processes   Profile the application and all child processes launched
                              by it.
  -k,--kernel-name TEXT       Set the regex to use for matching the kernel name.
                              The syntax is as follows:
                              	<kernel name>
                              Limit scope to given kernel name. The kernel name can be given by
                              part of the full kernel name, or by a regular expression to match
                              the full kernel name. 
  --kernel-id TEXT            Set the identifier to use for matching the kernel to profile. The identifier is 
                              of the format 'context-id:stream-id:kernel-name:correlation_id'.
                              Skip entries that shouldn't be matched, e.g. use '::foobar:2' to match the 
                              kernel with correlation_id is '2' and name contains 'foobar' in any context or stream.
                              Use ':7:foo:' to match any kernel in stream 7 and name contains 'foo'.
                              
  --devices TEXT              Set the GPU devices to enable profiling on.
                              Allowed values:
                              	all - change scope to all valid devices (default)
                              	comma - separated device IDs - change scope to specified devices
                              
  --page TEXT                 Select report page to output:
                                details: sections and rules
                                source: source code.
                              
  --print-source TEXT         Select source view:
                                IR
                                cuda
                                assembly
                                cuda,assembly
                              
  --resolve-source-file TEXT  Set a comma separated list of file paths to consider when resolving files for 
                              	the source output.
  --import-source TEXT        If available from -g, correlated CUDA source files are permanently
                              imported into the report. Allowed values :
                              	on/off
                              	yes/no
  -c,--launch-count TEXT      Limit the number of profiled kernel launches. 
                              The count is only incremented for launches that match the kernel filters. 
                              
  -s,--launch-skip TEXT       Set the number of kernel launches to skip before starting to profile kernels 
                              The number takes into account only launches that match the kernel filters 
                              
  --filter-mode TEXT:{global,per-gpu}
                              Set the filtering mode for kernel launches. Available modes:
                              	global - Apply provided launch filters on kernel launches collectively.(default) 
                              	per-gpu - Apply provided launch filters on kernel launches separately on each device.
                              	          Effective launch filters for this mode are --launch-count and --launch-skip 
                              
  --kill TEXT:{off,on}        Terminate the target application when the each application requested --launch-count was profiled.
                              This flag need valid --launch-count set. default set is 'off'
                              Allowed values:
                              	 on/off.
                              
  --print-kernel-args         Display kernel names with its arguments.
                              
  --target-processes-filter TEXT
                              Set the comma separated expressions to filter which processes are profiled.
                              	 <process name> Set the process name to filter. Regex matched processes are profiled.
                              
  --replay-mode TEXT:{application,kernel}
                              Choose replay mode used when not all events/metrics can be
                              collected in a single run. Allowed values:
                              	  kernel - each kernel invocation is replayed (default)
                              	  application - the entire application is replayed.This mode
                              			requires deterministic program execution.
                              
  --profile-from-start TEXT:{off,on}
                              Set if application should be profiled from its start. Allowed values:
                              	on  - enable profiling from start(default)
                              	off - disable profiling from start.
                              
  --disable-profiler-start-stop
                              Disable profiler start/stop. When enabled, cu(da)ProfilerStart/Stop API calls are ignored.
                              
  --csv                       Use comma-separated values in the output.
  --cache-control TEXT:{all,none}
                              Set the cache control behavior applied during kernel duration profiling. Allowed values:
                              	all  - flush all cache before tracing kernel duration
                              	none - no explicitly cache operations, just depending on prior GPU works (default)
                              
  --nvtx                      Enable NVTX support.
  --nvtx-include TEXT         Adds include statement to the NVTX filter, which allows selecting kernels to 
                              profile based on NVTX ranges.
  --nvtx-exclude TEXT         Adds exclude statement to the NVTX filter, which allows selecting kernels to
                              profile based on NVTX ranges.
  --quiet                     Suppress all ixkn-cli output.
  -o,--export-profile TEXT Excludes: --import-profile
                              Export the result file which can be imported later by IXKN-CLI.
                              	The ".ixkn-rep" suffix is appended if it is not already present.
                              	"%q{<ENV>}" in the file name string is replaced
                              with the value of the environment variable " < ENV >". If the
                              environment variable is not set it's an error.
                              	"%h" in the file name string is replaced with the
                              hostname of the system.
                              	"%%" in the file name string is replaced with "%".
                              	Any other character following "%" is illegal.
                              By default, this option disables any profiling information.
                              
  -f,--force-overwrite        Force overwriting all output files (any existing files will
                              be overwritten). Default is false, not force-overwrite.
                              
  -i,--import-profile TEXT:FILE Excludes: --export-profile
                              Import a result profile from a previous run.
                              
  --log-file TEXT             Send all tool output to the specified file, or one of the standard channel,
                              stdout (default) or stderr.
                              
  -v,--version                Print version information of this tool.
